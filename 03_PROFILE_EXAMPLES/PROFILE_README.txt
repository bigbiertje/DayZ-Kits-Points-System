PROFILE CONFIG INSTALL

Copy this folder:

03_PROFILE_EXAMPLES/DayZKitsPoints

to your DayZ server profile folder.

Example:

C:/Path/To/Your/Server/profiles/DayZKitsPoints

Files inside:

KitConfig.json      = free kits and special point kits
PointsConfig.json   = points settings, server key, zombie kill points
PointEvents.json    = DayZ writes point events here
DiscordQueue.json   = worker writes bought kits here
DiscordResponses.json = optional response tracking

Important:
The PointsConfig.json ServerKey must match the website special kit server_key and the worker config.
Example: server1
